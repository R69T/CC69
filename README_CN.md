# CC69

CC69 is a Windows desktop tool with a simple graphical interface that allows users to log in, enter URLs, start tasks, stop tasks, and monitor current status through easy button controls.

本頁面主要提供 CC69 EXE 版本 的介紹與下載說明。

# Main Features

### Designed for YouTube F4F (Follow-to-Follow) Testing

- 不需要費用
- 不需要在網路上曝光你的頻道
- 提供簡單 GUI 操作流程

---

- 圖形化操作介面，不需要輸入指令
- 支援登入狀態確認
- 可輸入網址並開始作業
- 可隨時停止接收新作業
- 可發佈任務，也可停止發佈任務
- 內建狀態紀錄區，方便查看目前執行狀況
- 顯示每日使用狀態與可用分數
- 支援多語言介面
