# CC69

CC69 は YouTube F4F（Follow-to-Follow）workflow テスト向けの Windows デスクトップツールです。

GUI インターフェースを通じて：

- ログイン
- URL入力
- workflow 開始
- workflow 停止
- タスク公開
- 状態確認

を簡単に行うことができます。

# 重要説明

CC69 は完全無料のコミュニティ型 workflow システムです。

システムの効果は：

- ユーザー参加
- タスク共有
- コミュニティ活動

によって成り立っています。

利用者が増えるほど workflow 活動も活発になります。
