# CC69

CC69 は YouTube F4F（Follow to Follow）テスト向けの Windows デスクトップツールです。

シンプルな GUI インターフェースにより、ログイン、URL入力、作業開始、停止、状態確認を簡単に行うことができます。

---

## Main Features

### Designed for YouTube F4F (Follow-to-Follow) Testing

- 無料で利用可能
- チャンネルを公開する必要なし
- シンプルな GUI 操作

---

- GUI インターフェース
- ログイン状態確認
- URL入力対応
- 作業開始 / 停止
- タスク公開機能
- タスク公開停止機能
- ログ表示機能
- デイリーステータス表示
- 多言語対応
