# CC69

CC69 是一款 Windows 桌面工具，提供簡單的圖形化介面，讓使用者可以透過按鈕完成登入、輸入網址、開始作業、停止作業與查看目前狀態。

本頁面主要提供 **CC69 EXE 版本** 的介紹與下載說明。

---

## 主要功能

- 圖形化操作介面，不需要輸入指令
- 支援登入狀態確認
- 可輸入網址並開始作業
- 可隨時停止接收新作業
- 可發佈任務，也可停止發佈任務
- 內建狀態紀錄區，方便查看目前執行狀況
- 顯示每日使用狀態與可用分數
- 支援多語言介面

## 使用方式

1. 下載 CC69 的 ZIP 檔。
2. 解壓縮 ZIP。
3. 執行資料夾內的 `CC69.exe`。
4. 按下登入按鈕，完成登入。
5. 輸入網址。
6. 按下「開始工作」。
7. 需要停止時，按下「停止工作」。

---

## 操作說明

### 開始工作

按下「開始工作」後，CC69 會開始檢查並執行可用作業。

### 停止工作

按下「停止工作」後，程式會停止接收新的作業。  
如果目前已有正在執行的作業，會等待該作業完成後再停止。

### 發佈任務

輸入網址後，可以使用「發佈任務」功能，讓該網址進入任務流程。

### 停止發佈任務

「停止發佈任務」只會停止你的網址繼續被領取，並不會停止你目前正在執行的工作。

## Windows 安全提示

第一次執行時，Windows 可能會顯示安全提醒。

如果你確認檔案來源正確，可以選擇：

```text
More info → Run anyway
```

這通常是因為 EXE 沒有購買數位簽章，不代表程式一定有問題。

## 注意事項

- 請確認電腦已安裝 Google Chrome。
- 使用前請先完成登入。
- 請保持網路連線正常。
- 若程式無法啟動，請重新解壓縮 ZIP 後再試一次。
- 請不要直接在壓縮檔內執行 EXE，建議先完整解壓縮。
