# CC69

CC69 is a Windows desktop application designed for YouTube F4F (Follow-to-Follow) testing.

Users can log in, submit URLs, start tasks, stop tasks, and monitor current status using a simple GUI interface.

---

## Main Features

### Designed for YouTube F4F (Follow-to-Follow) Testing

- No payment required
- No need to publicly expose your channel
- Simple GUI workflow

---

- Graphical user interface
- Login status support
- URL input support
- Start / Stop task control
- Publish task support
- Stop publishing tasks anytime
- Built-in status log panel
- Daily status and score display
- Multi-language interface support
